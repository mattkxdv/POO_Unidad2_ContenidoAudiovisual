# Instrucciones de ejecución

1. Abrir el proyecto en Visual Studio Code.
2. Abrir la carpeta del proyecto.
3. Ubicar src/poo/PruebaAudioVisual.java.
4. Ejecutar el método main.
5. Revisar en la consola los detalles de las películas, series, documentales, videos y cortometrajes.

El sistema utiliza Java y programación orientada a objetos.
